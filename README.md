# RedPandora Life

A personal GitHub Pages site about technology, faith, the outdoors, and the projects that make everyday life better.

## Local preview

This is a Jekyll site designed for GitHub Pages. With Ruby and Bundler installed, run:

```sh
bundle exec jekyll serve
```

Then open `http://localhost:4000`.

The main pages are Markdown files in the repository root. Shared navigation and page structure live in `_layouts/default.html`, and the visual system is in `assets/css/style.css`.
